# **App Name**: EduCentral

## Core Features:

- Role-Based Login: Login authentication for Admin, Student, and Lecturer roles.
- Admin Dashboard: Admin dashboard displaying overall school statistics and quick actions.
- Student Dashboard: Student dashboard to view class schedules, grades, and attendance.
- Lecturer Dashboard: Lecturer dashboard to manage course materials, input grades, and monitor student attendance.
- Student Records: Display of student data records for admins to manage.
- AI Study Suggestion: AI tool to suggest improvements in study material creation based on current affairs.
- Notifications: Push notification feature for alerts, schedules, and announcements.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) for a calm and trustworthy feel.
- Background color: Light grey (#F0F4F8), providing a clean and neutral backdrop.
- Accent color: Muted green (#81C784) to highlight key interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern reading experience.
- Use simple, clear icons to represent different functionalities.
- Maintain a consistent layout across all dashboards for ease of use.
- Use subtle transitions and animations to provide feedback on interactions.
